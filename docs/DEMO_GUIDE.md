# Judge demo guide

Open the public landing page and choose **Explore the demo**. The seeded freelancer website agreement demonstrates:

1. Agreement description and clarification.
2. Generated Contract IR and readable document.
3. Parity verification with linked fields.
4. Simulate tampering to change ₹50,000 to ₹45,000.
5. Execution is blocked until the approved value is restored.
6. Simulated Sepolia escrow and milestone progression.

All demo data stays in component state and is marked DEMO/SIMULATED. No wallet is connected, no funds move, and no transaction is reported as confirmed.
